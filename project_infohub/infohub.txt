პროექტის აღწერა:
RS.GE InfoHub Agent არის ხელოვნურ ინტელექტზე დაფუძნებული ასისტენტი რომელიც შექმნილია შემოსავლების სამსახურის საინფორმაციო და მეთოდოლოგიურ ჰაბზე ორიენტაციისთვის. პროექტი იყენებს RAG არქიტექტურას და LLaMA 3 მოდელს საგადასახადო და საბაჟო დავების გადაწყვეტილებების გასაანალიზებლად. სისტემას შეუძლია დაამუშაოს JSON ფორმატის დოკუმენტები გადაიტანოს ისინი ChromaDB ვექტორულ მონაცემთა ბაზაში და მომხმარებლის კითხვებს გასცეს დასაბუთებული პასუხები შესაბამისი ბმულების მითითებით. აპლიკაცია აწყობილია Python ზე Streamlit ის ინტერფეისით და იყენებს LangChain ის ბიბლიოთეკას. მთავარი მიზანია მომხმარებლისთვის საგადასახადო კანონმდებლობასთან და მეთოდოლოგიასთან წვდომის გამარტივება.

ინსტალაციის და გაშვების ინსტრუქცია:

გადმოწერეთ პროექტის ფაილები app.py და rs_ge_documents.json ერთ საქაღალდეში.

შექმენით requirements.txt ფაილი და ჩაწერეთ მასში საჭირო ბიბლიოთეკები: streamlit, langchain, langchain-groq, langchain-community, sentence-transformers, chromadb.

გახსენით ტერმინალი და დააინსტალირეთ ბიბლიოთეკები ბრძანებით pip install -r requirements.txt.

დააყენეთ სისტემურ ცვლადებში თქვენი GROQ API KEY ან ჩაწერეთ ის პირდაპირ კოდში (უკვე დაყენებულია llama-3.1-8b-instant უფსო ვერსია )ამის ადგილას.

გაუშვით აპლიკაცია ბრძანებით streamlit run app.py.

ბრაუზერში გაიხსნება ფანჯარა სადაც შეძლებთ კითხვების დასმას ქართულ ენაზე. დოკუმენტების ბაზა ავტომატურად შეიქმნება პირველივე გაშვებისას.
